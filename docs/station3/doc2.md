# 機能一覧

| No  | カテゴリー           | 優先度 | 要求内容                                                 |
| --- | -------------------- | ------ | -------------------------------------------------------- |
| 1   | 会員登録             | 高     | 極力簡単に会員登録したい                                 |
| 2   | 旅のしおり　　　　   | 高     | 旅行の日程と、宿や交通手段など決定している内容を記載する |
| 3   | 持ち物リスト　　　　 | 低     | 旅行の持ち物のステータス状況を表示する                   |
| 4   | お財布               | 低     | 予算と支出の総額と差額を表示する                         |
| 5   | 旅のブログ           | 中     | 日付ごとに写真と文章を登録                               |
| 6   | フォトブック作成     | 中     | PDF入稿でフォトブックを印刷注文する（外部API使用予定）   |
| 7   | LINE連携             | 高     | PDF入稿でフォトブックを印刷注文する（外部API使用予定）   |

# 画面設計図

## オブジェクトの洗い出し

### 1.旅行(Trip):

・タイトル
・日付（旅行開始日〜旅行終了日）
・宿（宿泊費分）
・交通機関切符
・その他の予約
・予算（全体）
・予算（一人あたり）
・支出
・写真
・日記

### 2.ユーザー(User):

・名前
・メールアドレス
・パスワード

### 3.メンバー(Member):

・名前
・LINE ID

### 4.かばん(Bag):

・持ち物

### 5.フォトブック(Photobook):

・タイトル
・日付
・写真
・テキスト
・旅行の概要

| オブジェクト              | 対応する要件No | 満たしている要件の説明                                           |
| ------------------------- | -------------- | ---------------------------------------------------------------- |
| 旅行(Trip)                | 2,3,4,5,6,7    | 旅行の日程や宿、交通手段など決定している内容が記録でき連携できる |
| ユーザー(User)            | 1　　　　      |                                                                  |
| メンバー(Member)          | 2,3,4,7        | LINE ID登録により情報の連携ができる                              |
| かばん（Bag）             | 3              | 旅行の持ち物のステータス状況をを記録・表示できる                 |
| フォトブック（Photobook） | 2,5,6          | 旅行の記録をPDFとして保存。フォトブックとして印刷注文できる      |

・会員の削除

### 2.旅行の作成・編集・削除:

・新しい旅行の作成
・既存の旅行の編集
・旅行の削除

・新しい行程・予算の作成
・既存の行程・予算の編集
・行程・予算の削除
・メンバーへの共有

### 4.メンバー管理:

・新しいメンバーの登録
・既存メンバーの編集
・メンバーの削除

### 5.持ち物の作成・編集・削除

・新しい持ち物の登録
・既存の持ち物の編集
・持ち物の削除

### 6.支出の作成・編集・削除

・新しい支出の登録
・既存の支出の編集
・支出の削除
・メンバーへの共有

### 7.日記の作成・編集・削除

・新しい日記の作成

・日記の削除

### 8.フォトブック作成

・PDFの作成
・PDFの削除
・フォトブック印刷
