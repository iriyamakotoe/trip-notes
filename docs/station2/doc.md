> **背景**  
> 友人が、家族旅行するにあたってこれまでノートへ手書きなどアナログで行っていたが、便利なアプリがないか探していた。  
> 色々と探したそうだが、友人が欲しい旅行の持ち物リスト、行程、予算・支出管管理、アルバム機能など欲しい機能がひとつのアプリで行えるものがなかなか見当たらないと言っていた。  
> 友人は、夫と小学生低学年の子ども１人の３人家族。共働きで忙しい毎日で、また性格的に大雑把なO型なので、アプリは簡単に操作できるものでないと長続きできなさそうだと心配している。  
> 車の免許を持っていないため、いつも移動は公共交通機関を利用しており、地方では現地での交通手段をチェックしないといけないらしいが、何分忙しいため行き当たりばったりなことが多いのだそう。  
> アプリに記録したものは、最終的には旅の記録としてフォトブックとして印刷発注できたら理想だと言っていた。

# 「家族向け旅行支援アプリ開発」要件定義

### 概要

家族向け旅行支援アプリの開発。旅行の計画から、旅行中の予算・支出管理、思い出までを管理できるようにする。

### 現状の課題

- 旅行前 - 行程、手配状況など家族間でスムーズに情報伝達できていない
- 旅行中 - 何にどのくらいお金を使ったのか不明確​
- 旅行後 - 残せるかたちでアウトプットできていない​

### ゴール設定

- 旅行の計画から旅行中のお財布管理、思い出までを一つのアプリで管理する
  - 機能を絞り、シンプルで簡単な操作性
  - それぞれの機能で家族間で連携しやすい機能をつける
- 紙媒体などで印刷・保存できるようにトする​

### 現状の課題とゴールとのギャップ

- **アプリの利便性**<br>
  現状: 機能ごとに複数のアプリを利用しなくてはならない<br>
  ゴール: 各機能を極力シンプルにして１つのアプリで横断して管理できるようにする<br>
- **旅行の記録保存**<br>
  現状: 旅行の記録が写真以外に残せていない<br>
  ゴール: 旅行の記録をPDFでファイル保存、必要に応じてフォトブック印刷できるようにする<br>
